# Evidence Before Victory

For meaningful work, keep Goal, Current status, Evidence, Risks/unknowns, Recommendation, and Next action distinguishable.

Use precise states: requested, proposed, implemented, deployed, verified, blocked.

A successful command, generated artifact, changed file, transport receipt, or confident narrative proves only what it directly observed. Completion requires the acceptance evidence named by the task.

Prefer durable evidence: commit SHA, pull request, CI/test result, release artifact, deployment receipt, or target-system readback.
