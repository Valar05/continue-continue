name: Mission Boundary
description: Reject silent substitution of the requested outcome, owner, tool, lane, evidence, or delivery surface
---

Review only the changed behavior in this pull request. Fail the check if the PR solves an adjacent problem while silently changing the commissioned outcome, owner, execution tool/lane, explicit exclusions, acceptance evidence, or delivery surface.

A different architecture may be better, but it must be presented as an explicit proposal rather than smuggled into the implementation. Require the PR description and code to distinguish requested behavior from proposed expansion.
